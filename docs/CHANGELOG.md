# Changelog

Registro dei miglioramenti tecnici di easylab-web: cosa è cambiato, **perché**, e quali file
sono coinvolti. Il README resta la guida operativa (installazione, backup, aggiornamento); qui
si annota solo l'evoluzione del codice e dell'infrastruttura.

> **Convenzione:** una voce per intervento, con la motivazione. Il "perché" è la parte che
> non si ricostruisce dal diff — è il motivo per cui questo registro esiste.

## Come è organizzato

Questa pagina è solo l'indice: una riga per voce, le più recenti in cima. Il testo delle voci
sta in `docs/changelog/`, un file per mese (`AAAA-MM.md`), diviso per decadi quando un mese
supera le 2.000 righe circa (settembre 2026: `2026-09-01-10.md`, `2026-09-11-20.md`,
`2026-09-21-30.md`). Fino al 2026-09-29
era tutto in questo file, arrivato a 7.500 righe: non si leggeva più per intero, né a occhio né
con gli strumenti che lo aggiornano.

Per aggiungere una voce: scriverla in cima al file del periodo corrente (`## AAAA-MM-GG — Titolo`,
separata dalla precedente da `---`), e aggiungere la riga qui sotto, in cima alla sezione del
periodo. Un periodo nuovo vuol dire un file nuovo, una sezione nuova qui e una voce in `nav` di
`mkdocs.yml`. I rimandi "vedi CHANGELOG del AAAA-MM-GG" nelle altre pagine restano validi: la
data porta alla voce da qui.
